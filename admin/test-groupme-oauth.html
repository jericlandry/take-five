Take Five · GroupMe OAuth test page

Not wired into the real admin UI — standalone page for testing the connect flow end to end before it goes into takefive-ensemble-admin.html. See Trello #39.

1. Log in (same OTP flow as the real app)




2. Connect GroupMe


Opens a popup to GroupMe's login. Once you authorize, the popup posts the token back here automatically.






3. Create a GroupMe group for a test circle
